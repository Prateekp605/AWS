Amazon EC2
Amazon EC2 provides scalable compute capacity in the AWS cloud. We can easily launch and manage virtual servers (instances).

 What is Amazon EC2?
Amazon EC2 is an Infrastructure as a Service (IaaS) that provides:
Virtual machines within the cloud.
We can select which OS we want such as Linux and Windows.
We can configure our CPU, RAM, Storage and Network.
We are able to scale our compute resources.

1. EC2 Instances
An EC2 instance is a virtual server in the AWS cloud.

2. Instance Types
We have different instance types in EC2:
General Purpose – T, M
Compute Optimised – C
Memory Optimised – R
Storage Optimised – I

3. Key Pairs
Key pairs are used to authenticate securely.
Public key - This key will be stored by AWS on your instance.
Private key – This key will be downloaded and securely stored by you.
For Linux instances we often use SSH.

4. EC2 Instance Status
There are several statuses for your EC2 instance:
Pending – Instance is being launched.
Running – Instance is up and running.
Stopping – Instance is stopping.
Stopped – Instance is stopped.
Terminated – Instance has been permanently deleted.
